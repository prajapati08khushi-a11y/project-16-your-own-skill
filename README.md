# Project 16 – Your Own Skill

## Project Objective
To develop and improve personal skills using AI tools and digital technology.

## Methodology
Identify a skill, learn using digital resources, practise through activities, evaluate progress, and improve the results.

## Expected Outcome
Improved practical knowledge, creativity, confidence, digital literacy, and independent learning ability.

## Tools Used
Computer, internet, and AI tools.
